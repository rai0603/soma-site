01

這是什麼

Soma 不是「對話框裡的 AI」，是一隻浮在你桌面、看得到、會行動的夥伴。

  • 桌面形象：VRM／Live2D 角色透明浮在桌面、常駐置頂，會對嘴、會做表情。
  • 會說話：逐句串流語音，講話時嘴型同步。
  • 有記憶：每個角色各自記住跟你聊過的重點。
  • 會行動（進階版）：開網頁、整理檔案、控制音樂——走出對話框操作真實桌面。
02

快速開始

從安裝到說第一句話，四個步驟。

  1. 把 Soma Agent 拖進「應用程式」再開啟（直接從 dmg 開會找不到）。
  2. 選擇介面語言。之後可以在設定改，也不影響角色講什麼語言。
  3. 在 ⚙ 設定 → 授權填 Email 開始 7 天試用，或貼上你購買的序號。
  4. 在 ⚙ 設定 → AI 模型貼上 API key（或選 Ollama 走免費本地模型），然後就能開始聊了。

Soma 刻意不顯示在程式塢——桌面上那隻半透明角色就是它。找不到視窗時用 Spotlight 搜「Soma」。

03

AI 模型與金鑰

Soma 不轉賣 AI 額度。你用自己的 API key 直接連到模型供應商，用多少付多少給他們，對話不經過我們的伺服器。這就是 BYOK（自備金鑰）。

Anthropic（Claude）
console.anthropic.com｜唯一支援桌面工具、看圖與 PDF
OpenAI（GPT）
platform.openai.com｜純對話
Google Gemini
aistudio.google.com｜純對話
Ollama（本機）
ollama.com｜完全免費、資料不外流，純對話

你的 key 只存在這台電腦的 secrets.json（檔案權限 600），只有 Rust 端讀得到——不會進到網頁層，也不會傳給我們。

費用看模型。Haiku 最便宜，一般閒聊一則大約零點幾元台幣；改用 Opus 或每次都帶大量附件會明顯往上。想完全免費就用 Ollama。

04

授權與試用

在 ⚙ 設定 → 授權填 Email 就能開始 7 天免費試用，不需要付款資訊。序號會寄到你的信箱，換電腦時用得到。試用期是基礎版功能。

試用結束後角色、設定和聊天記憶全部保留，只是不能再送訊息。購買後貼上序號就能接著用。

買斷制、沒有月費：基礎版 NT$599、進階版 NT$899（多兩位角色與桌面工具）、Podcast 雙角色對話加購 NT$399。

基礎版綁 1 台、進階版 2 台。換電腦時先在舊機按「解除綁定」，再到新機貼同一組序號。

05

購買與啟用

在官網 soma-agent.com 選方案結帳，付款由 Paddle 處理（支援信用卡與常見電子錢包）。買斷制，付一次就永久可用。

  1. 到官網「支持方案」選基礎版或進階版；需要雙角色對話再加購 Podcast。
  2. 在 Paddle 結帳視窗完成付款，Email 請填你收得到信的那一個。
  3. 序號會寄到該信箱，通常幾分鐘內送達。
  4. 打開 Soma Agent → ⚙ 設定 → 授權，貼上序號按「啟用」。

沒收到序號信：先看垃圾信件匣，再到官網「找回序號」頁輸入同一個 Email 重寄。還是沒有就寄 soma-agent.com">support@soma-agent.com。

官網「我的帳號」頁可以用 Email 收登入連結（不必設密碼），查看名下的授權、已綁定的裝置，以及解除舊電腦的綁定。

Podcast 加購要在結帳時填入既有序號，才會掛到同一組授權上。退款依官網退款政策辦理。

06

角色、記憶與語言

⚙ 設定 → 角色可以切換或新增角色。每個角色有自己的人設、記憶和外觀，互不干擾。

語言和聲線是「每個角色各自」的設定，隨時可換——任何角色都能講任何語言。回應語言在 ⚙ 設定 → 角色改，聲線在 → 語音改。

角色會記住聊過的事，並慢慢整理成長期記憶。可以在角色設定裡查看或清除。

有 Podcast 加購時，點輸入列上的雙人圖示可以讓兩隻角色互相聊（你旁觀）或三方一起聊。

07

語音

在 ⚙ 設定 → 語音填入 Azure Speech 的金鑰與區域，角色才會出聲；沒設定時會退回系統聲音。

語音輸入：按住右邊的 Option 鍵說話，放開送出。需要在系統設定給「輸入監控」權限，熱鍵可以改。

08

匯入自己的模型

⚙ 設定 → 形象與外觀 → 匯入模型，支援 .vrm 與 Live2D（資料夾或 zip）。自己匯入的模型不受版本限制，基礎版也能用。

Live2D 貼圖必須是 RGBA PNG。用調色盤（indexed）格式的貼圖會讓角色卡在「準備中…」。

09

疑難排解

沒有程式塢圖示
正常，桌寵刻意不顯示在程式塢，只有桌面上那隻角色。
角色卡在「準備中…」
多半是匯入模型的貼圖不是 RGBA PNG，轉檔後重新匯入。
加圖片卻說只支援 Claude
圖片與 PDF 只有 Anthropic 模型能讀，把對話模型切回 Claude。
沒有聲音
確認 ⚙ 設定 → 語音的 Azure 金鑰與區域都填了，並檢查系統音量沒靜音。
語音輸入沒反應
需要在系統設定 → 隱私權與安全性 → 輸入監控裡允許 Soma。
抓網頁沒有內容
網頁工具只有 Anthropic 模型可用，且要給完整的 http(s) 網址。
