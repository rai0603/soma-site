01

这是什么

Soma 不是「对话框里的 AI」，是一只浮在你桌面、看得到、会行动的伙伴。

  • 桌面形象：VRM／Live2D 角色透明浮在桌面、常驻置顶，会对嘴、会做表情。
  • 会说话：逐句串流语音，讲话时嘴型同步。
  • 有记忆：每个角色各自记住跟你聊过的重点。
  • 会行动（进阶版）：开网页、整理文件、控制音乐——走出对话框操作真实桌面。
02

快速开始

从安装到说第一句话，四个步骤。

  1. 把 Soma Agent 拖进「应用程序」再打开（直接从 dmg 开会找不到）。
  2. 选择界面语言。之后可以在设置改，也不影响角色讲什么语言。
  3. 在 ⚙ 设置 → 授权填 Email 开始 7 天试用，或贴上你购买的序列号。
  4. 在 ⚙ 设置 → AI 模型贴上 API key（或选 Ollama 走免费本地模型），然后就能开始聊了。

Soma 刻意不显示在程序坞——桌面上那只半透明角色就是它。找不到窗口时用 Spotlight 搜「Soma」。

03

AI 模型与密钥

Soma 不转卖 AI 额度。你用自己的 API key 直接连到模型供应商，用多少付多少给他们，对话不经过我们的服务器。这就是 BYOK（自备密钥）。

Anthropic（Claude）
console.anthropic.com｜唯一支持桌面工具、看图与 PDF
OpenAI（GPT）
platform.openai.com｜纯对话
Google Gemini
aistudio.google.com｜纯对话
Ollama（本机）
ollama.com｜完全免费、数据不外流，纯对话

你的 key 只存在这台电脑的 secrets.json（文件权限 600），只有 Rust 端读得到——不会进到网页层，也不会传给我们。

费用看模型。Haiku 最便宜，一般闲聊一条大约几毛钱；改用 Opus 或每次都带大量附件会明显往上。想完全免费就用 Ollama。

04

授权与试用

在 ⚙ 设置 → 授权填 Email 就能开始 7 天免费试用，不需要付款信息。序列号会寄到你的邮箱，换电脑时用得到。试用期是基础版功能。

试用结束后角色、设置和聊天记忆全部保留，只是不能再发消息。购买后贴上序列号就能接着用。

买断制、没有月费：基础版 NT$599、进阶版 NT$899（多两位角色与桌面工具）、Podcast 双角色对话加购 NT$399。

基础版绑 1 台、进阶版 2 台。换电脑时先在旧机按「解除绑定」，再到新机贴同一组序列号。

05

购买与激活

在官网 soma-agent.com 选方案结账，付款由 Paddle 处理（支持信用卡与常见电子钱包）。买断制，付一次就永久可用。

  1. 到官网「支持方案」选基础版或进阶版；需要双角色对话再加购 Podcast。
  2. 在 Paddle 结账窗口完成付款，Email 请填你收得到信的那一个。
  3. 序号会寄到该邮箱，通常几分钟内送达。
  4. 打开 Soma Agent → ⚙ 设置 → 授权，粘贴序号按「激活」。

没收到序号邮件：先看垃圾邮件箱，再到官网「找回序号」页输入同一个 Email 重寄。还是没有就寄 soma-agent.com">support@soma-agent.com。

官网「我的账号」页可以用 Email 收登录链接（不必设密码），查看名下的授权、已绑定的设备，以及解除旧电脑的绑定。

Podcast 加购要在结账时填入既有序号，才会挂到同一组授权上。退款依官网退款政策办理。

06

角色、记忆与语言

⚙ 设置 → 角色可以切换或新增角色。每个角色有自己的人设、记忆和外观，互不干扰。

语言和声线是「每个角色各自」的设置，随时可换——任何角色都能讲任何语言。回复语言在 ⚙ 设置 → 角色改，声线在 → 语音改。

角色会记住聊过的事，并慢慢整理成长期记忆。可以在角色设置里查看或清除。

有 Podcast 加购时，点输入栏上的双人图标可以让两只角色互相聊（你旁观）或三方一起聊。

07

语音

在 ⚙ 设置 → 语音填入 Azure Speech 的密钥与区域，角色才会出声；没设置时会退回系统声音。

语音输入：按住右边的 Option 键说话，放开发送。需要在系统设置给「输入监控」权限，热键可以改。

08

导入自己的模型

⚙ 设置 → 形象与外观 → 导入模型，支持 .vrm 与 Live2D（文件夹或 zip）。自己导入的模型不受版本限制，基础版也能用。

Live2D 贴图必须是 RGBA PNG。用调色板（indexed）格式的贴图会让角色卡在「准备中…」。

09

疑难排解

没有程序坞图标
正常，桌宠刻意不显示在程序坞，只有桌面上那只角色。
角色卡在「准备中…」
多半是导入模型的贴图不是 RGBA PNG，转档后重新导入。
加图片却说只支持 Claude
图片与 PDF 只有 Anthropic 模型能读，把对话模型切回 Claude。
没有声音
确认 ⚙ 设置 → 语音的 Azure 密钥与区域都填了，并检查系统音量没静音。
语音输入没反应
需要在系统设置 → 隐私与安全性 → 输入监控里允许 Soma。
抓网页没有内容
网页工具只有 Anthropic 模型可用，且要给完整的 http(s) 网址。
