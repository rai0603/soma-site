01

이게 뭔가요

Soma는 "채팅창 안의 AI"가 아니라, 바탕화면에 떠 있고, 눈에 보이고, 행동할 수 있는 파트너예요.

  • 모습이 있어요: VRM／Live2D 캐릭터가 배경 없이 바탕화면에 떠서 항상 위에 있고, 입도 표정도 움직입니다.
  • 목소리가 있어요: 문장 단위로 스트리밍되고 입 모양이 함께 움직입니다.
  • 기억이 있어요: 캐릭터마다 당신과 나눈 이야기의 요점을 따로 기억합니다.
  • 손이 있어요 (어드밴스드): 웹 열기, 파일 정리, 음악 조작 — 대화 밖에서 진짜 바탕화면을 움직입니다.
02

시작하기

설치부터 첫 마디까지 네 단계예요.

  1. Soma Agent를 "응용 프로그램"으로 끌어다 놓은 뒤 여세요 (dmg에서 바로 열면 나중에 못 찾습니다).
  2. 인터페이스 언어를 고르세요. 나중에 바꿀 수 있고, 캐릭터가 쓰는 언어와는 별개예요.
  3. ⚙ 설정 → 라이선스에서 이메일을 넣어 7일 체험을 시작하거나, 구매한 시리얼을 붙여넣으세요.
  4. ⚙ 설정 → AI 모델에서 API 키를 붙여넣고 (또는 Ollama를 골라 무료 로컬 모델을 쓰고) 대화를 시작하세요.

Soma는 일부러 Dock에 표시되지 않아요 — 바탕화면의 반투명 캐릭터가 앱 본체입니다. 창을 잃어버리면 Spotlight에서 "Soma"를 검색하세요.

03

AI 모델과 키

Soma는 AI 사용량을 재판매하지 않아요. 본인 API 키로 공급자에 직접 연결해서 쓴 만큼 그쪽에 냅니다. 대화가 저희 서버를 거치지 않아요. 이게 BYOK입니다.

Anthropic (Claude)
console.anthropic.com | 데스크톱 도구·이미지·PDF를 지원하는 유일한 선택
OpenAI (GPT)
platform.openai.com | 대화만
Google Gemini
aistudio.google.com | 대화만
Ollama (로컬)
ollama.com | 무료, 데이터가 밖으로 안 나감, 대화만

키는 이 맥의 secrets.json(권한 600)에만 저장되고 Rust 쪽에서만 읽을 수 있어요 — 웹 계층에도, 저희에게도 전달되지 않습니다.

비용은 모델에 따라 달라요. Haiku가 가장 싸서 가벼운 대화 한 번에 몇 원 수준이고, Opus나 매번 큰 첨부를 쓰면 눈에 띄게 올라갑니다. 완전 무료로 쓰려면 Ollama를 쓰세요.

04

라이선스와 체험

⚙ 설정 → 라이선스에서 이메일을 넣으면 7일 무료 체험이 시작돼요 (결제 정보 불필요). 시리얼도 메일로 보내드리니 기기를 바꿀 때를 위해 보관하세요. 체험은 베이직 기능입니다.

체험이 끝나도 캐릭터, 설정, 기억은 모두 남아요. 메시지를 보낼 수 없게 될 뿐입니다. 구매하고 시리얼을 붙여넣으면 이어서 쓸 수 있어요.

구독 없는 영구 구매: 베이직 NT$599, 어드밴스드 NT$899 (캐릭터 2명과 데스크톱 도구 추가), Podcast 두 캐릭터 대화 추가 NT$399.

베이직은 1대, 어드밴스드는 2대까지예요. 옮길 때는 이전 맥에서 "연결 해제"를 먼저 누르고, 새 맥에 같은 시리얼을 붙여넣으세요.

05

구매와 인증

공식 사이트 soma-agent.com에서 플랜을 고르고 Paddle로 결제합니다(신용카드 및 주요 간편결제 지원). 한 번 결제하면 계속 쓰는 매절 방식입니다.

  1. 사이트의 「플랜」에서 베이직 또는 어드밴스를 고르고, 두 캐릭터의 대화가 필요하면 Podcast를 추가로 구매합니다.
  2. Paddle 결제창에서 결제를 완료합니다. 메일을 실제로 받을 수 있는 주소를 입력하세요.
  3. 라이선스 키가 그 주소로 발송됩니다(보통 몇 분 이내).
  4. Soma Agent를 열고 ⚙ 설정 → 라이선스에 키를 붙여넣은 뒤 「인증」을 누릅니다.

키가 오지 않으면 먼저 스팸함을 확인하고, 사이트의 「일련번호 찾기」 페이지에서 같은 메일 주소로 다시 받아보세요. 그래도 없으면 soma-agent.com">support@soma-agent.com으로 문의해 주세요.

사이트의 「내 계정」에서는 메일로 로그인 링크를 받습니다(비밀번호 불필요). 보유한 라이선스와 인증된 기기를 확인하고, 예전 컴퓨터의 인증을 해제할 수 있습니다.

Podcast 추가 구매는 결제 시 기존 라이선스 키를 입력해야 같은 라이선스에 연결됩니다. 환불은 사이트의 환불 정책을 따릅니다.

06

캐릭터, 기억, 언어

⚙ 설정 → 캐릭터에서 바꾸거나 추가할 수 있어요. 각자 성격, 기억, 외형을 완전히 따로 갖고 있습니다.

언어와 목소리는 캐릭터마다 설정하고 언제든 바꿀 수 있어요 — 어떤 캐릭터든 어떤 언어든 말할 수 있습니다. 응답 언어는 ⚙ 설정 → 캐릭터, 목소리는 → 음성에서 바꿔요.

캐릭터는 나눈 이야기를 기억하고 조금씩 장기 기억으로 정리해요. 캐릭터 설정에서 보거나 지울 수 있습니다.

Podcast를 추가 구매하면 입력창 위의 두 사람 아이콘으로 두 캐릭터가 대화하게 하거나 (당신은 구경) 직접 끼어들 수 있어요.

07

음성

⚙ 설정 → 음성에서 Azure Speech 키와 지역을 넣으면 목소리가 나와요. 설정하지 않으면 시스템 음성으로 대체됩니다.

음성 입력: 오른쪽 Option 키를 누른 채 말하고 떼면 전송돼요. macOS의 "입력 모니터링" 권한이 필요하고, 단축키는 바꿀 수 있습니다.

08

내 모델 가져오기

⚙ 설정 → 외형 → 모델 가져오기. .vrm과 Live2D(폴더 또는 zip)를 지원하고, 직접 가져온 모델은 요금제 제한을 받지 않아요.

Live2D 텍스처는 RGBA PNG여야 해요. 인덱스(팔레트) PNG를 쓰면 캐릭터가 "준비 중…"에서 멈춥니다.

09

문제 해결

Dock에 아이콘이 없어요
정상이에요. 일부러 Dock에 표시하지 않습니다. 바탕화면의 캐릭터가 앱 본체예요.
캐릭터가 "준비 중…"에서 멈춰요
대개 가져온 텍스처가 RGBA PNG가 아닌 경우예요. 변환해서 다시 가져오세요.
첨부가 Claude 전용이라고 나와요
이미지와 PDF는 Anthropic 모델에서만 됩니다. 대화 모델을 Claude로 되돌리세요.
소리가 안 나요
⚙ 설정 → 음성의 Azure 키와 지역을 확인하고, 시스템 볼륨이 음소거인지도 보세요.
음성 입력이 반응하지 않아요
시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링에서 Soma를 허용하세요.
웹을 가져와도 내용이 없어요
웹 도구는 Anthropic 전용이고, 완전한 http(s) 주소가 필요합니다.
